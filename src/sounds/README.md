# Completion sound

Source supplied by the project owner: `01KJ62M058J29M6EJP3XRMS14W.mp3`.
Source metadata credits Epidemic Sound; this is separate from the CC0 guitar samples.

Only the first variation (the first chapter) is included. Leading and trailing
silence was trimmed at -50 dB, tiny edge fades prevent clicks, and `atempo=1.2`
establishes the faster timing. Playback is then two semitones higher and 6 dB
quieter, while retaining the 1.2x timing. The source file is unchanged.
