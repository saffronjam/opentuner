# Guitar samples

Meta Open Sound, Meta Steel Guitar, CC0 1.0.
https://github.com/facebookincubator/Meta-open-sound/tree/514c926efecdb3c7812bf00eedf8e5c8d61dd681/systems/instruments/meta-steel-guitar

Medium-velocity samples on each open string, plus E5 on the high E string.
Trimmed to 2.5 seconds, faded for 0.25 seconds, mono MP3 at 96 kbit/s.
The app transposes the nearest recording for other target notes.
Application source remains MIT; these audio recordings are CC0.

Playback rates compensate for the median pitch measured between 0.25 and
1.5 seconds at 48 kHz using Pitchy (clarity > 0.95), referenced to A=440 Hz.
